FOZAYX Games website package

1) Upload the contents of this folder to the root of your GitHub Pages repository.
2) The Cricket 07 card checks for cricket07.jpeg in the root folder first. The current workspace did not contain that uploaded image, so a LaunchBox EA SPORTS Cricket 07 logo is configured as a fallback. If you have your own cricket07.jpeg, upload it beside index.html and it will be used.
3) Spider-Man Ultimate Power and Skater Boy artwork are referenced from public image URLs. If those hosts change or block hotlinking, the cards fall back to original FOZAYX-styled SVG title artwork.
4) Original SVG title artwork is included for FOZAYX projects that did not have verified logos. These are custom title cards, not official publisher logos.
5) Keep fx-logo.png if you already have it; the navbar falls back to assets/logos/fozayx-mark.svg if it is missing.
6) Keep Pro_Evolution_Soccer_2013_cover.jpg in the site root if you have it; the PES detail page falls back to its generated title card if missing.
7) Some local download links (cricket07.apk, aura.apk) still require those APKs to be placed in the site root.
8) Third-party game files and trademarks should only be distributed when you have permission.

IMAGE SOURCES USED AS OPTIONAL REMOTE FALLBACKS
- Cricket 07 EA SPORTS title logo: https://gamesdb.launchbox-app.com/games/images/89340-cricket-07 (image hosted at images.launchbox-app.com).
- Spider-Man Ultimate Power app artwork: FileHippo image URL used in the card.
- Skater Boy title artwork: Apple App Store image URL used in the card.
These are third-party copyrighted images. The website references them remotely rather than packaging copies. Check the source site's terms and replace them with artwork you have permission to use if required.
